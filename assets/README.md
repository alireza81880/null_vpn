# Capacitor Source Assets
Place your high-resolution source images here for @capacitor/assets:

Required Files:
- logo.png (or icon-only.png) -> 1024x1024 px (Transparent background recommended for adaptive icon foreground)
- icon.png (or icon-foreground.png / icon-background.png) -> 1024x1024 px (App Launcher Icon)
- splash.png (or splash-dark.png) -> 2732x2732 px (Splash Screen)

Generate command:
  npm run generate-assets
